demo-joke is a tiny program that writes one one-line joke to a file: during the demo, an AI colleague refactors the whole backend, then pauses and asks whether it should also fix the typo in the human's job title. A joke about working beside an AI coding agent, and about who the demo really belongs to.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
