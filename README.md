demo-joke is a tiny program that writes one one-line joke to a file: an agent builds the demo in eleven minutes, with tests, and the human spends the other forty-nine rehearsing how to say "we built this" with a straight face. A joke about working beside an AI coding agent, and about who gets to say "we" after the demo.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
